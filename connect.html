Connection instructions

Connection requires separate administrator authorization in Intuit.

This information page has no OAuth callback handler, token fields or sign-in form. Never enter an Intuit password, app secret or token on this site.

  1. Review the app, callback route, requested scope and local protected storage.
  2. After approval and Intuit eligibility confirmation, use Intuit's supported authorization interface.
  3. The administrator supplies the approved app identity and refresh token privately in the local masked terminal bootstrap, after confirming the company for that grant.
  4. Verify the connection separately before reviewing any invoice upload.

Permission scope

The requested scope is com.intuit.quickbooks.accounting. Intuit grants broad accounting API access; it has no attachment-only OAuth scope. The local adapter limits its exposed write workflow to attachments. No Payments or OpenID scope is requested.

The Intuit-hosted OAuth Playground bootstrap is proposed; production assessment acceptance for this app remains unverified. This page is not that callback.
