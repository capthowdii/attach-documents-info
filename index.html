Attach Documents

A private Windows tool for Team Z Restoration LLC to attach approved timesheet PDFs to existing QuickBooks Online invoices.

Company use

The target subscription is QuickBooks Online Simple Start. Operation runs on the authorized Windows PC. This website provides app information and policy drafts; it does not access QuickBooks or receive timesheets.

Limited workflow

The intended workflow checks the invoice identity, searches existing attachments, compares file fingerprints and verifies uploaded bytes and invoice association. It does not create or send invoices, change financial values or make payments. Attachments are marked not to be included with invoice sends.

Current status

The integration is disabled while setup is reviewed. No live connection is implemented by these pages.
